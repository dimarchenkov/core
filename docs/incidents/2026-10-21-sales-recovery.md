## Учётные факты

Для каждой продажи AQSI созданы:

- завершённая `Sale` с исходными позициями и временем чека;
- успешная карточная `PaymentAttempt` с идентификатором слипа в технических метаданных;
- успешная `Fiscalization`, привязанная к исходному receipt ID;
- складское движение только для позиции, однозначно связанной с каталогом.

Для каждой продажи без чека созданы:

- завершённая `Sale`;
- успешная наличная `PaymentAttempt` без провайдера и интеграции;
- отдельная `Fiscalization(status=skipped)` с причиной
  `operator_selected_cash_without_receipt`;
- складское движение только для двух указанных каталожных товаров.
