# v0.6.0 — Rental Operations

Core now supports the complete daily rental lifecycle without SQLAdmin: customer management,
checkout, partial and full return, operational catalog navigation, and a permanent passport for
every physical rental item.

## Added

- Customers and RentalOrder foundations with immutable historical snapshots;
- atomic rental checkout and partial/full return workflows;
- LOST handling and derived overdue contracts;
- operational Product catalog and rental-aware navigation;
- optional retail price capture during Intake;
- product cards with current price, barcode and printable PDF labels;
- RentalAsset lifecycle passport and chronological history;
- customer active and completed rental history;
- append-only maintenance and damage journals;
- before/after condition photos backed by Media storage.

## Architecture

- RentalAsset and RentalOrder remain independent aggregates;
- checkout and return remain application workflows owning their transactions;
- lifecycle history is derived from existing immutable order facts;
- maintenance, damage and condition-photo records are append-only Rental evidence;
- no rental economics, analytics or dashboard is included in this release.
