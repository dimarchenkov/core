# Core v0.7.0 — Rental Economics & Business Insights

Релиз завершает Sprint 10G и добавляет вычисляемую экономику эксплуатации арендуемых предметов.

## Возможности

- неизменяемая стоимость приобретения RentalAsset из завершённой приёмки;
- стоимость обслуживания как источник эксплуатационных расходов;
- фактическая выручка, расходы, чистый доход, средняя аренда и продолжительность аренд;
- дата окупаемости и вычисляемые признаки эффективности;
- агрегированная экономика Variant и Product;
- сортировка каталога по доходу, количеству аренд, прибыли и последней аренде;
- фильтры по окупаемости, отсутствию аренд, высоким расходам и длительному простою.

## Архитектура

- экономика рассчитывается read service на основании существующих операционных фактов;
- аналитические значения и признаки не хранятся как отдельные статусы;
- повреждение не признаётся расходом без записи обслуживания;
- RentalAsset и RentalOrder aggregates не изменены;
- Checkout и Return workflows не изменены.
